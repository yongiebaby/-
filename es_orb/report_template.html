検証ルール
  • OR = RTH開始から 5 / 15 / 30 / 60 分の高安。祝日・短縮取引日は除外。
  • シグナル: OR完成後の足の終値がORH超（ロング）/ ORL未満（ショート）。ヒゲだけ抜けて終値がOR内の足は見送り、その本数を「ヒゲ本数」として記録。
  • エントリー: シグナル足の次の足の始値で成行（+1tickスリッページ）。
  • 損切り: ブレイク足のlow/high・ブレイク足の前3本のlow/high・OR中値・逆側のOR。いずれも1tick外側。約定は1tickスリッページ。
  • 次の足の始値がすでに損切りラインを越えて損切りが成立しない場合は見送り、件数をカウント。
  • 利確: 実約定価格からRR × リスク（0.2 / 0.5 / 1 / 1.5 / 2）。指値なのでスリッページなし。
  • 同じ足で損切りと利確の両方に届いた場合は損切り扱い。件数をカウント。
  • 引け: 16:00 ETで成行決済（1tickスリッページ）。手数料は往復$4、1枚 = $50/pt。
  • 再エントリー: 一度シグナルが出た側は、終値がORの内側に戻ってから改めてブレイクした場合のみ再エントリー。保有中に出たブレイクも無効になる。
  • 再エントリーの種類: 1日1回 / 同方向のみ / 逆方向のみ / 両方可。上限 2・3・無制限。
  • エントリー受付の終了: 11:30 / 13:30 / 15:30 / 16:00。
  • 特徴量フィルター（19種）: 日足ATRのレジーム、OR幅・オーバーナイト値幅・前日値幅のATR比、ブレイク足の大きさ、日足SMA20に対する位置、ギャップ、オーバーナイトの値動き、前日RTHとオーバーナイトのボリュームプロファイル（POC・バリューエリア）、前日高安・オーバーナイト高安までの余地、RTH VWAP、5分足EMA20/50、相対出来高（OR・ブレイク足）、デルタ比。ブレイク前のヒゲ本数も条件として使用。
  • ボリュームプロファイルは5分足の出来高を高安の範囲に均等配分して計算（バリューエリア70%）。オーバーナイトは前日16:00–18:00を除く18:00–09:30。
  • 採用条件: ISの各年でトレード100件以上。
ウォークフォワード

OOS（未使用期間）の成績

2年間のISで最適化し、翌1年のOOSに適用する手順を4回繰り返して、OOSだけをつなげた成績です。スコア1は「ネット損益/最大DD」と「期待値」、スコア2は「ネット損益/最大DD」と「勝率」の順位を平均したもの。ISの各年でトレードが100件未満の設定は不採用にしています。

「ベースのみ」はフィルターなしの3,200通りの上位20件から、「単独条件」はそれに特徴量1つの条件を掛けた候補（約2,300通り）から、「2条件」は単独条件の上位同士を組み合わせた候補も含めた中から選んだもの。条件の閾値はISのシグナル分布の分位点で決めています。

特徴量

ボラティリティ・レジーム・コンフルエンスの効き目

1日1回・受付16:00・フィルターなしのトレードを、各特徴量の上位20%と下位20%（カテゴリは +1 と −1）に分けて期待値を比べたもの。t値の絶対値が2を超え、かつ年ごとの差の符号が6年中5年以上そろっていれば、効果がありそうと言える目安です。方向を持つ特徴量は、ブレイク方向に有利なほど大きくなるよう符号をそろえています。
