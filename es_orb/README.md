# ES ORB（オープニングレンジ・ブレイクアウト）検証

ES 5分足（ATASエクスポート, 2020-01〜2025-12）で、OR終値ブレイク → 次足始値の成行順張りを検証するコード。

## 実行

```bash
pip install numpy pandas numba scipy
python es_orb/run.py --out results part1.csv part2.csv   # zipも可。複数ファイルは時系列に連結
python es_orb/report.py --out results --findings results/findings.html  # CSVとreport.htmlを生成
```

## ルール

| 項目 | 内容 |
|---|---|
| OR | RTH(09:30 ET)開始から 5 / 15 / 30 / 60 分の高安 |
| シグナル | OR完成後の足の**終値**がORH超 / ORL未満。ヒゲだけ抜けた足は見送り、本数をカウント |
| エントリー | シグナル足の次の足の始値で成行 (+1tick) |
| 損切り | ブレイク足のlow/high・ブレイク足の前3本のlow/high（ETH足を含む）・OR中値・逆側OR。1tickバッファ、約定は1tickスリッページ |
| 損切り不成立 | 次足の始値がすでに損切りライン越え → 見送り、件数を記録 |
| 利確 | 実約定価格から 0.2 / 0.5 / 1 / 1.5 / 2 RR。指値でスリッページなし |
| 同一足で両方 | 損切り扱い、件数を記録 |
| 引け | 16:00 ETで成行決済 (1tick) |
| コスト | 往復$4、1枚 = $50/pt |
| 再エントリー | 1日1回 / 同方向のみ / 逆方向のみ / 両方可 × 上限 2・3・無制限。一度シグナルが出た側は終値がOR内に戻るまで無効（保有中のブレイクも同様） |
| 受付時間 | エントリー足の開始が 11:30 / 13:30 / 15:30 / 16:00 より前 |
| 除外日 | RTHの足が70本未満の日（祝日・短縮取引日） |

## 最適化（ウォークフォワード）

| ステップ | IS | OOS |
|---|---|---|
| 1 | 2020–2021 | 2022 |
| 2 | 2021–2022 | 2023 |
| 3 | 2022–2023 | 2024 |
| 4 | 2023–2024 | 2025 |

1. フィルターなしのベース 3,200 通り（OR 4 × 損切り 4 × RR 5 × 再エントリー 10 × 受付終了 4）をISで評価し、スコア1・スコア2の上位10件ずつを候補にする。
2. 各候補に特徴量1つの条件を掛ける（閾値はISのシグナル分布の20/40/60/80%点、カテゴリは +1 / ≥0 / ≤0 / =0。ヒゲ本数条件も含む）。
3. ベースごとに単独条件の上位6件同士を組み合わせた2条件も評価する。
4. ベースのみ / 単独条件まで / 2条件まで の3段階それぞれで最良の設定をOOSに適用する。

- **採用条件: ISの各年でトレード100件以上**（満たさない設定は順位付けの対象外）
- スコア1 = 「ネット損益/最大DD」と「期待値(R)」のパーセンタイル順位の平均
- スコア2 = 「ネット損益/最大DD」と「勝率」のパーセンタイル順位の平均
- フィルターはエンジン内でシグナルごとに判定する（見送ったシグナルの後も再エントリー規則どおりに続行）

## 特徴量（features.py）

すべてブレイク足の終値時点で確定している情報のみ。方向を持つものはブレイク方向に有利なほど大きくなるよう符号をそろえる。

| グループ | 特徴量 |
|---|---|
| ボラティリティ | 日足ATR14の1年パーセンタイル、OR幅/ATR14、オーバーナイト値幅/ATR14、前日RTH値幅/ATR14、ブレイク足値幅/5分ATR20、ブレイク足値幅/OR幅 |
| レジーム | 始値 − 日足SMA20、ギャップ、オーバーナイトの値動き |
| プロファイル | 始値と前日RTHバリューエリア・オーバーナイトのバリューエリアの位置、終値 − オーバーナイトPOC |
| 価格水準 | 前日高安・オーバーナイト高安までの余地 |
| コンフルエンス | 終値 − RTH VWAP、5分足EMA20 − EMA50 |
| 出来高 | OR出来高/過去20日平均、ブレイク足出来高/同時刻の過去20日平均、デルタ/出来高 |

ボリュームプロファイルは5分足の出来高を高安の範囲に均等配分して計算（バリューエリア70%）。オーバーナイトは18:00–09:30 ET。日足の値はRTHセッションから自前で計算し、ATASの集計列には依存しない。

## ファイル

- `data.py` CSV読み込み・RTH日単位の配列化・OR計算
- `engine.py` 1設定のシミュレーション（numba）
- `backtest.py` 指標・ベースグリッド
- `features.py` 特徴量の計算
- `confluence.py` 特徴量の統計とウォークフォワード
- `analysis.py` ヒゲ本数・時間帯・ブレイク足サイズ・異例カウントの集計
- `report.py` / `report_template.html` CSVとHTMLレポートの出力
